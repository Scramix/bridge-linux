# Changelog

All notable changes to Bridge Linux are documented here.

## [0.015]

### Added

* Added `hash.cat`, a Windows catalog file containing cryptographic hashes for the NSIS installer.

### Changed

* `Docs.chm` and `hash.cat` are now included with the Bridge Linux Setup and are no longer listed as separate release assets.

## [0.01]

### Added

* Added the NSIS source code for the Bridge Linux installer.
* Added the source code for the CHM documentation.
* Added the compiled Bridge Linux installer.
* Added the compiled CHM documentation.
