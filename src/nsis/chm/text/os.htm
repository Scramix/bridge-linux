What is the Operating System?

An operating system, commonly shortened to OS, is the software that manages your computer and allows you to interact with it.

The operating system connects the programs you use with the hardware inside your computer. It manages things such as memory, storage, processors, devices, and running programs.

An operating system is made up of more than just the kernel. It also contains system programs, drivers, libraries, utilities, and usually some kind of user interface.

For example, when you open a file, the program you are using asks the operating system to access that file. The operating system then works with the kernel and hardware to retrieve the data.

Examples of Operating Systems

There are many different operating systems. Some examples include:

  • Windows
  • Linux
  • macOS
  • FreeDOS
  • OS/2

Bridge Linux is an operating system based on Linux. It uses the Linux kernel along with other software to provide a complete operating system that you can use on your computer.
