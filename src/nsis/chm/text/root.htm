What is root?

In Linux, root is the name of the system's most powerful user account. The root account has permission to access and change almost everything on the computer, including important system files and settings.

Bridge Linux normally does not require you to use the root account directly. When an operation requires administrator permissions, Bridge Linux will ask you to authenticate before allowing the operation to continue.

If you are coming from Windows, you can think of root as being similar to the Administrator account.

Why is root important?

Because root has permission to make major changes to the system, it should be used carefully. Normal applications and everyday tasks do not need root permissions.
