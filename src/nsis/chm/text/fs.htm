What is a File System?

A file system, or FS for short, is basically the thing that keeps track of how your files are stored on a hard drive or solid-state drive. We will look at SSDs in another file.

Without a file system, a storage device is basically just a big collection of raw data. If you read the disk directly, you will see raw bytes, usually displayed as hexadecimal numbers. That is very incomprehensible if you do not know what the data means.

That is why file systems exist. They organize the data on your storage device so the operating system can understand things like files, folders, file names, and where the actual data is stored.

There are many different file systems, such as ext4, BTRFS, NTFS, exFAT, and FAT32. Bridge Linux supports several file systems, with ext4 being the recommended choice for most users.
