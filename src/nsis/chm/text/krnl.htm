What is the kernel?

The kernel is the core part of an operating system. It acts as a bridge between the software you use and the hardware in your computer.

The kernel manages important parts of your computer, such as the CPU, memory, storage devices, and other hardware. When a program needs to perform an operation that requires hardware, it can ask the kernel to perform it.

For example, when you save a file, the program does not directly control the storage device. Instead, it asks the kernel to write the data to the appropriate location.

The kernel also manages running programs and makes sure they can share the computer's resources without interfering with each other.

Bridge Linux uses the Linux kernel. However, the kernel is only one part of an operating system. The next page will explain what an operating system actually is.
